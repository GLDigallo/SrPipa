# SrPipa

## Descripción

SrPipa es una aplicación web orientada a un comercio físico que permite consultar productos mediante un catálogo digital moderno, accesible y adaptable a distintos dispositivos.

El objetivo principal es mejorar la experiencia de los clientes y facilitar el trabajo diario del comercio mediante una administración sencilla y una comunicación directa por WhatsApp.

---

## Estado del proyecto

🚧 En desarrollo

Actualmente el proyecto se encuentra en etapa de análisis, planificación y definición de arquitectura.

Todavía no existe código de implementación.

---

## Objetivos

- Crear un catálogo moderno.
- Priorizar la accesibilidad.
- Adaptarse a dispositivos antiguos y modernos.
- Facilitar la comunicación mediante WhatsApp.
- Mantener una arquitectura escalable y mantenible.

---

## Tecnologías previstas

- Java 21
- Spring Boot
- Maven
- PostgreSQL
- React
- OpenCode como asistente de desarrollo

---

## Filosofía del proyecto

El desarrollo estará dirigido por documentación y reglas de arquitectura antes de implementar código, utilizando IA como herramienta de asistencia y no como reemplazo del criterio del desarrollador.
