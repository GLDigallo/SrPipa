# SrPipa

## Visión del Proyecto

SrPipa es una aplicación web de tipo catálogo diseñada para un comercio físico.

El objetivo principal del proyecto es ofrecer una experiencia rápida, moderna y sencilla para que los clientes puedan consultar los productos disponibles y comunicarse con el comercio mediante WhatsApp.

El sistema no está pensado como una tienda online tradicional. Su propósito es facilitar la consulta de productos y mejorar la comunicación entre clientes y trabajadores.

## Público objetivo

La aplicación está dirigida a clientes que desean consultar productos de un comercio físico de forma rápida desde cualquier dispositivo, y a trabajadores que necesitan administrar el catálogo de manera simple e intuitiva.

## Objetivos principales

- Facilitar la consulta de productos.
- Mantener una experiencia moderna y accesible.
- Reducir la cantidad de consultas repetitivas.
- Integrar la comunicación mediante WhatsApp.
- Permitir una administración sencilla del catálogo.
